# Research preprint v1.0.0

Environmental recurrence selects a costly memory-use allele without a resolved one-bit population benefit

This first release supplies the prospectively specified manuscript, supplement, three figures, authenticated producer/analyzer/auditor source, all 22 saved estimates, all block and path records, the bounded literature-search archive and reproducibility checks. A separate complete-outcomes archive contains the full per-update records and prospectively selected candidate-level audit rows.

The main result is recurrence-attributable enrichment of a mutable private-memory-use allele under one fixed search-budget cost, with no resolved one-bit population-accuracy benefit. Negative, unresolved and descriptive adverse outcomes remain explicit. Manuscript/data: CC BY 4.0. Original code: MIT. Not externally peer reviewed.
